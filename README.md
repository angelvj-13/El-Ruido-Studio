# EL RUIDO · STUDIO v3

Aplicación de tablero creativo con tarjetas editables, tareas marcables, escenas y archivo local multimedia.

## Publicación
Sube todos los archivos de esta carpeta a la raíz del repositorio de GitHub Pages, reemplazando los anteriores. Conserva una copia de seguridad de cualquier dato de versiones anteriores.

## Datos
Las tareas y textos se guardan en localStorage, los adjuntos en IndexedDB. No hay sincronización entre dispositivos. Exporta copias completas desde Datos. Los archivos no se suben al repositorio de GitHub.

## Nota
Los diseños de personajes de la cabecera son un recorte de la maqueta visual aprobada; las escenas precargadas contienen el material textual disponible.
