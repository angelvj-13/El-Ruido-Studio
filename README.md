# EL RUIDO · STUDIO v4

Conserva el tablero y los datos locales de v3 (`el-ruido-studio-v3-state` y IndexedDB).

## Biblioteca incorporada
Material recuperado de los archivos accesibles de la conversación: diseños, storyboard, fotograma, cronograma, referencia, maqueta y prueba MP4. Están en `biblioteca/` y se consultan en la pestaña **Biblioteca**.

## Datos nuevos
Los archivos que el usuario sube desde la web permanecen en IndexedDB del navegador, no en el repositorio GitHub ni en Finder. Exportar copias desde Datos. Para sincronización real entre dispositivos hará falta una integración de nube y autenticación.

## Publicación
Subir todos los archivos y carpetas a la raíz del repositorio y conservar la URL de GitHub Pages.
