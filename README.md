# EL RUIDO · STUDIO
Aplicación web instalable (PWA) para el seguimiento del cortometraje **El Ruido**.

## Funciones
- 3 misiones semanales libres, 10–15 minutos por sesión.
- Banco inicial de 18 retos; 12 para el primer mes.
- Completar, deshacer, cambiar, posponer y crear misiones.
- Progreso por disciplinas, historial, logros, notas y enlaces.
- Datos guardados en `localStorage`; exportación/importación JSON.
- Diseño responsive e instalación desde Safari en iPhone.

## Publicar en GitHub Pages
1. Crea un repositorio público `el-ruido-studio`.
2. Sube todos los archivos de esta carpeta a la raíz de la rama `main`.
3. En **Settings → Pages**, selecciona **Deploy from a branch → main → /(root)** y guarda.
4. La dirección prevista será `https://angelvj-13.github.io/el-ruido-studio/` si el propietario es `angelvj-13`.
5. En Safari del iPhone: **Compartir → Añadir a pantalla de inicio**.

## Importante
El almacenamiento local **no sincroniza dispositivos**. Exporta periódicamente una copia JSON. No elimines datos del navegador sin copia.
